# Personal Website and Data Science Blog

This repository contains the source files for my personal academic website and data science blog, built with **Quarto** and **R**.

The website serves as a central place for my academic profile, projects, coursework-related writing, and reproducible data analysis. All blog posts are maintained within the same RStudio/Quarto project and the same GitHub repository, while each blog post keeps its own code, data, and figures in a separate folder.
